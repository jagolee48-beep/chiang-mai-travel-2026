# 清邁旅行 Chiang Mai 2026 10/25~10/31

清邁七天六夜互動旅行手冊，目前版本含提醒與公告、每日行程、住宿、餐廳．咖啡與包車資訊。

## 網站原始碼

- `index.html`：網站結構與靜態資訊。
- `style.css`：米白、森林綠與金棕的響應式版面。
- `app.js`：每日行程切換、餐飲卡片及 Google Maps 導航。

無需安裝套件或建置。照片引用外部來源，來源連結保留於頁面。

## 存取與編輯

網站目前由 Sites 提供私人存取。這份靜態原始碼本身沒有登入、權限控管或資料庫，也沒有設定 GitHub Pages 或自動部署。請勿將原始碼中的 noindex 標記視為存取控制。

行程可由擁有者透過 ChatGPT 修改，網頁內的多人編輯功能尚未建置。
